# Plant Disease Detection System

A machine learning-based system for automated identification of plant diseases using computer vision. Achieves **95% classification accuracy** on a dataset of 80,000+ plant images.

## 🌟 Features

- **95% Classification Accuracy** across multiple plant diseases
- **80,000+ Training Images** for robust disease detection
- **Responsive Web Interface** for easy image upload and diagnosis
- **Real-time Processing** with instant results
- **Multiple Plant Species** support

## 🚀 Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/guptaritik17/Plant_disease_prediction_model.git

# Install dependencies
pip install -r requirements.txt

# Run the application
python main.py
```

## 🖥️ Usage

3. View results with confidence scores
